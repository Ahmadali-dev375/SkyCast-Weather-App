# 🌤️ SkyCast Weather

SkyCast is a responsive weather website that presents current weather information through a clean and user-friendly interface.

## 🌐 Live Demo

[Open SkyCast Weather](https://skycast-weather-aa.web.app)

## ✨ Features

- Search weather information by city
- Current temperature display
- Humidity information
- Wind-speed information
- Visibility information
- Responsive interface
- Light Light and dark theme
- Multiple informational pages

## 🛠️ Technologies

- HTML
- CSS
- JavaScript
- Weather API
- Firebase Hosting
